跟着《动手学深度学习》（PyTorch 版）的章节顺序读，一章一个 notebook。每个 notebook 里除了书上的代码，还写了自己整理的理解和各节「习题」的解答。

## 章节内容

### 第 1 章 引言

基本没有代码，主要是概念梳理。

- 1.1 日常生活中的机器学习
- 1.2 机器学习中的关键组件：数据、模型、目标函数、优化算法
- 1.3 各种机器学习问题：监督学习（回归、分类、标记、搜索、推荐、序列学习）、无监督学习、与环境互动、强化学习
- 1.4 起源；1.5 深度学习的特点；1.6 总结

### 第 2 章 预备知识

后面各章都要用到的工具，代码按 PyTorch 版逐个跑一遍，每节末尾附「习题 2.x」的解答。

- 2.1 数据操作：张量的创建与形状、运算符与广播机制、索引和切片、原地操作节省内存、与 NumPy 互转
- 2.2 数据预处理：用 pandas 读 CSV、处理缺失值、转换成张量格式（用 `data/house_tiny.csv`）
- 2.3 线性代数：标量/向量/矩阵/张量、按元素运算、`sum` 降维与 `keepdims`、点积与矩阵乘法、范数
- 2.4 微积分：导数与数值逼近、偏导数与梯度、链式法则
- 2.5 自动微分：`backward` 与梯度累积、非标量输出、分离计算（`detach`）、控制流下的求导
- 2.6 概率：抽样与大数定律、概率公理与随机变量、联合概率/条件概率/贝叶斯定理、期望和方差
- 2.7 查阅文档：`dir`、`help` 与官方文档的查法
- 2.8 小结
